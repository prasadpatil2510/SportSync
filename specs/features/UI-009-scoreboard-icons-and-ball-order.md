# UI-009 — Scoreboard icons and ball order

Status: verified

## Intent

Improve the readability of the established scoring scoreboard without changing scoring behaviour.

## Acceptance criteria

- [x] Striker and non-striker use cricket-bat icons.
- [x] Every current-over delivery uses a fixed circular badge.
- [x] Current-over deliveries appear chronologically: first ball, second ball, third ball and onward.
- [x] Overs containing extra illegal deliveries can scroll horizontally without truncation.

## Verification

- Android staging build compiles.
- Existing backend and specification checks pass.
